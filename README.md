# Websites

Websites built with Claude code

## Getting started

Requires [Node.js](https://nodejs.org) (any recent version — no dependencies to install).

```bash
npm start
```

Then open **http://localhost:3000** in your browser.

## Project structure

```
public/          # your website files — edit these
  index.html     # the page
  style.css      # styles
  script.js      # javascript
server.js        # tiny local dev server (port 3000)
```

Edit anything in `public/` and refresh the browser to see your changes.
To use a different port: `PORT=8080 npm start`.
